# NutriVision Documentation

This directory contains the project documentation and delivery artifacts for
the NutriVision capstone project.

## Deliverables

| Document | Contents |
| --- | --- |
| [Project Planning & Management](pdfs/nutrivision_project_planning.pdf) | Project overview, objectives and scope, timeline and milestones, task assignment and roles, risk assessment and mitigation, and key performance indicators. |
| [Literature Review](pdfs/nutrivision_literature_review.pdf) | Feedback and evaluation, suggested improvements, and final grading criteria. |
| [Requirements Gathering](pdfs/nutrivision_requirements_gathering.pdf) | Stakeholder analysis, user stories and use cases, functional requirements, and non-functional requirements. |

The PDFs are kept in `docs/pdfs` so they remain versioned with the source code
and can be reviewed alongside the implementation.
