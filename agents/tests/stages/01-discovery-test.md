# Stage 01 Test: Discovery and Acceptance

Copy this file to `agents/tests/features/<feature>.md` and complete it before
implementation.

## Acceptance cases

- [ ] Primary user outcome is observable.
- [ ] Happy path has a concrete expected result.
- [ ] Validation blockers are listed.
- [ ] Loading behavior is listed.
- [ ] Empty data behavior is listed.
- [ ] Failure/offline/unavailable behavior is listed.
- [ ] Authorization and privacy assumptions are listed.

## Reuse review

- [ ] Existing screen/widget/helper search completed.
- [ ] Existing domain entity/repository/use case search completed.
- [ ] Existing test and fake search completed.
- [ ] New abstraction is justified and named.

## Required outputs

- Feature scope and acceptance criteria.
- A list of expected executable test files.
- Risks and unresolved questions.
