# Stage 07 Test: Release and CI Readiness

## Checklist

- [ ] `dart format .` passes.
- [ ] `flutter analyze` passes.
- [ ] `flutter test` passes.
- [ ] Relevant integration/evaluation tests pass.
- [ ] CI runs the same required checks.
- [ ] Release configuration has no development secrets or endpoints.
- [ ] Assets and permissions are verified.
- [ ] Logs/telemetry are redacted and privacy-justified.
- [ ] Feature flags and rollback behavior are documented if needed.
- [ ] Release notes and known limitations are written.
