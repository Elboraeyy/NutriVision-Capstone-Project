# Stage 03 Test: UI and Design System

## Visual checklist

- [ ] Existing colors, typography, spacing, and responsive helpers are reused.
- [ ] Feature-specific widgets are in the feature folder.
- [ ] Shared widgets are used before creating duplicates.
- [ ] Overlay headers and floating navigation preserve transparent space.
- [ ] Narrow, normal, and wide layouts do not clip or overflow.
- [ ] Long text, loading, empty, and failure states are readable.

## Accessibility checklist

- [ ] Important controls have meaningful labels.
- [ ] Tap targets are reasonable.
- [ ] Contrast remains readable.
- [ ] Meaning does not depend on color alone.
- [ ] Keyboard/focus/text scaling concerns are considered.

## Executable proof

- [ ] Widget test renders the initial state.
- [ ] Widget test covers the main interaction.
- [ ] Widget test covers loading/error/empty state when applicable.
- [ ] Route/navigation behavior is tested when changed.
