# Feature Test Plans

Create one Markdown plan per meaningful feature here, for example:

```text
agents/tests/features/meal_history.md
agents/tests/features/meal_scan.md
agents/tests/features/recipe_recommendations.md
```

Start from the applicable stage files in `../stages/`. Record the acceptance
cases, architecture checks, UI states, data/API cases, AI evaluations,
integration journeys, and the exact executable Dart test files that prove them.

Do not use this folder for executable tests. Executable tests belong in the
repository's `test/` and `integration_test/` directories.
