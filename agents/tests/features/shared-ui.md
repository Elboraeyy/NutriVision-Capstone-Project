# Shared UI Test Plan

## Acceptance matrix

- [ ] Theme tokens render consistently across features.
- [ ] Responsive helpers work at narrow, normal, and wide widths.
- [ ] Overlay scaffold preserves transparent header space and scroll behavior.
- [ ] Shared buttons and fields expose meaningful labels and tap targets.
- [ ] AppToast renders success, error, warning, and info variants correctly.
- [ ] No feature creates a duplicate of an existing shared control.

## Required executable coverage

- [ ] Widget tests for each shared control changed.
- [ ] Responsive widget tests for changed layout constraints.
- [ ] Accessibility/semantics checks for important controls.
- [ ] Visual/manual review against the NutriVision design language.
